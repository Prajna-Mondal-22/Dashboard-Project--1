# 📊 Madhab Ka Store – Sales Analytics Dashboard

An interactive **Power BI Sales Analytics Dashboard** developed to analyze retail sales performance and generate meaningful business insights from raw sales data.

## 📌 Project Overview

The objective of this project is to transform raw retail sales data into an interactive and visually informative dashboard using **Microsoft Power BI**.

The dashboard provides a consolidated view of key business metrics such as **Sales, Quantity, Profit, Average Order Value, product performance, customer performance, payment methods, and regional trends**.

It demonstrates how data analytics and visualization can be used to understand business performance and support data-driven decision-making.

## 🎯 Project Objectives

* Analyze overall sales and profit performance
* Identify high-performing product categories
* Analyze state-wise and regional performance
* Track monthly and quarterly sales trends
* Understand customer purchasing patterns
* Analyze different payment methods
* Create interactive KPI-based visualizations
* Present business insights through an easy-to-understand dashboard

## 📊 Key Dashboard Metrics

The dashboard includes important KPIs such as:

* **Total Sales**
* **Total Quantity**
* **Total Profit**
* **Average Order Value**
* **Monthly / Quarterly Performance**
* **Category-wise Performance**
* **State-wise Performance**
* **Customer-wise Sales**
* **Payment Mode Analysis**
